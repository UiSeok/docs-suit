# 글쓰기 테마 스킬

문서를 쓰기 전에 테마 엔진으로 규칙을 조립하고, 그 규칙을 따라 쓴다.

1. 요청에서 문서 종류와 독자를 정한다. 종류는 `resume`, `slides`, `report`, `teamwork` 중 하나이고, 맞는 것이 없으면 종류 없이 조립한다. 독자는 `professor`, `teammate`, `recruiter`, `listener`, `reader` 중에서 고르고, 말하지 않았으면 비워 둔다. 종류의 기본 독자가 쓰인다.
2. 사용자가 문체, 어법, 분량, 글자수, 공개 범위를 말했으면 `--set 축=값` 과 `--chars` 로 넘긴다. 축과 값은 `python3 theme.py list` 로 본다.
3. 이 스킬 폴더에서 `python3 theme.py compose --kind <종류> [--audience <독자>] [--set …] [--chars N]` 를 돌린다.
4. 출력된 지침 전체를 이번 문서의 규칙으로 따른다. 지침의 "공통 바닥" 이 시키는 대로, 쓰기 전에 틀리면 결과가 쓸모없어지는 것만 두세 개 묻는다.
5. 다 쓴 뒤 `[확인 필요: …]` 표시가 남았으면 모아서 보여 준다.

사용자가 결과의 말투나 모양이 마음에 안 든다고 하면, 어느 축의 문제인지 짚고 그 축의 다른 값으로 다시 조립해 대표 문단 하나를 견줘 보인다. 고른 값을 계속 쓰고 싶어 하면 `python3 theme.py set <축> <값> [--audience <독자>]` 로 개인 설정에 남긴다.
