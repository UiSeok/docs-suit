# 공통 바닥

어떤 테마를 골라도 지키는 규칙이다.

- 모르면 지어내지 않는다. 근거가 없는 자리는 `[확인 필요: 무엇을]` 으로 남기고, 글을 마칠 때 이 표시를 모아 보여 준다.
- 확인한 사실과 추정을 같은 문장에 섞지 않는다. 추정은 추정이라고 적는다.
- 수치는 받은 자료에 있는 그대로 쓴다. 반올림하거나 그럴듯한 숫자를 만들지 않는다.
- 쓰기 전에, 틀리면 결과가 쓸모없어지는 것만 두세 개 묻는다. 받은 자료로 알 수 있는 것은 묻지 않는다. 답이 없으면 가정을 밝히고 진행한다.
- 개수는 "세 가지가 있다", "네 군데다" 처럼 단위 명사로 센다. "셋이다", "넷입니다" 처럼 수사를 서술어로 세우지 않는다.
- "다양한", "효율적인", "혁신적인" 처럼 정보가 없는 수식어 대신 구체적인 명사와 수치를 쓴다.
