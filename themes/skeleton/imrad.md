# 목적 · 방법 · 결과 · 고찰

실험 보고서와 연구 레포트의 골격이다.

- 절의 순서는 목적, 방법, 결과, 고찰, 참고문헌이다. 맨 앞에 요약 한 문단을 둔다.
- 방법 절은 다른 사람이 같은 실험을 다시 할 수 있을 만큼 쓴다. 장비, 데이터, 절차, 조건이다.
- 결과 절에는 해석을 넣지 않는다. 숫자와 표, 그림만 쓴다.
- 고찰 절에서 결과를 해석하고, 한계와 다음에 바꿀 점을 쓴다.

## 보기

### 목적
정류장 대기 시간의 시간대별 차이 확인
### 방법
정류장 세 곳, 7일, 30분 단위 관찰
### 결과
출근 시간대 평균 12분 (표 1)
### 고찰
표본이 7일이라 계절 차이는 보지 못했다
