# 문제 · 해결 · 효과

내가 겪은 경험을 하나씩 쓰는 골격이다. 이력서, 포트폴리오, 프로젝트 회고에 맞다.

- 경험 하나는 문제 상황, 해결 방법, 효과의 세 줄로 쓴다.
- 해결 방법에는 어떤 대안이 있었고 왜 이것을 골랐는지를 쓴다.
- 효과는 수치로 쓴다. 수치가 없으면 "측정하지 않았다"고 쓰고 지어내지 않는다.
- 기능을 만들었다는 나열은 쓰지 않는다. 기능은 누구나 만든다.

## 보기

- 문제: 출근 시간대 정류장 대기 12분
- 해결: 7일 관찰로 시간대별 대기를 재고, 증차와 노선 변경 중 비용이 적은 증차를 골라 제안
- 효과: 시뮬레이션상 대기 12분 → 6분
