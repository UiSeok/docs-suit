# 문제 · 원인 · 대책

무엇이 잘못됐고 어떻게 고칠지 쓰는 골격이다. 팀플 문제 정리나 개선 제안에 맞다.

- 절의 순서는 문제, 원인, 대책, 남은 문제다.
- 문제 절은 누가 어떤 불편을 겪었는지 수치로 쓴다.
- 원인 절은 확인한 원인과 추정을 나눠 쓴다. 추정은 추정이라고 적는다.
- 대책 절은 대책마다 어느 원인을 막는지 이어 붙인다.

## 보기

### 문제
출근 시간대 대기 12분, 다른 시간대의 2배
### 원인
확인: 배차 간격은 같음. 추정: 수업 시작 시각이 몰림
### 대책
8시대 1회 증차. 수업 시작 시각이 몰리는 원인을 막는다
