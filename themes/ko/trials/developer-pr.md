# PR 설명
class: developer
kind: pr
audience: peer-dev
order: 1

동료 개발자가 리뷰할 PR 설명을 써 줘.
- 정류장 단말기 기록에서 시간대별 평균 대기 시간을 내는 집계 스크립트를 더했다.
- 승객이 정류장에 들어온 시각과 버스에 탄 시각의 차이를 대기 시간으로 본다.
- 하루 기록 12만 건을 40초에 집계한다.
- 탑승 기록이 없는 승객은 빼는데, 전체의 3% 가 빠진다.
- 지난주 하루치 기록으로 손으로 계산한 값과 맞춰 봤다.
- 자정을 넘긴 기록을 어떻게 처리했는지 봐 줬으면 한다.
