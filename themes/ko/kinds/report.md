# 보고서 · 레포트

수업 과제나 조사 결과로 내는 글이다. 읽는 사람은 대개 선생님이나 교수, 조교, 또는 결과를 받아 볼 사람이다.

쓰기 전에 받을 것
- 과제 안내문 원문 전체. 분량, 형식, 마감, 평가 기준, AI 사용 규정이 들어 있다.
- 내가 모은 자료와 실험 데이터, 메모 원문.

지킬 것
- 표지에는 과목명, 과제명, 학번이나 반·번호, 이름, 제출일을 쓴다. 공개 범위가 인터넷 공개면 학번과 반·번호는 뺀다.
- 맨 앞에 요약 한 문단을 둔다. 무엇을 했고 무엇을 알아냈는지다.
- 과제 안내문이 요구한 항목을 빠짐없이 다뤘는지 끝에서 표로 대조한다. 열은 "요구 항목, 다룬 절" 이다.
- 결론에는 한계와 다음에 바꿀 점을 쓴다.
