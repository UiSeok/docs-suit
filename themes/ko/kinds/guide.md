# 가이드 · README · 위키

처음 온 사람이 이 문서만 보고 혼자 해낼 수 있게 하는 글이다. 사용 설명서, 온보딩 문서, 저장소 README, 팀 위키의 방법 문서가 여기 든다.

쓰기 전에 받을 것
- 이 문서를 읽고 독자가 해낼 일 하나. 설치인지, 첫 배포인지, 신청 절차인지다.
- 실제로 돌려 본 명령과 화면, 설정값의 원문. 기억으로 쓴 명령은 틀리기 쉽다.

골격
- 첫 문단에 이것이 무엇이고 누가 언제 읽는지를 쓴다.
- 다음 절은 "빠른 시작" 이다. 처음부터 끝까지 한 번 성공하는 가장 짧은 길을 번호 목록으로 쓴다.
- 번호 목록의 단계 하나에는 동작 하나만 쓴다. 두 동작을 함께 해야 할 때만 한 단계에 묶는다.
- 조건과 주의는 그 동작보다 앞에 쓴다. 독자는 단계를 읽는 대로 실행해서, 동작 뒤에 붙은 주의는 이미 늦다.
- 그다음 자주 하는 일을 절 하나에 하나씩 쓴다. 절 제목은 "~하려면" 처럼 독자가 하려는 일로 쓴다.
- 자주 막히는 곳이 알려져 있으면 "문제 해결" 절에 증상과 해결을 짝지어 둔다.
- 명령과 설정은 복사해서 그대로 돌릴 수 있게 전체를 싣는다. 사람마다 바꿀 값은 `<이름>` 꼴로 표시한다.

하지 않는 것
- 돌려 보지 않은 명령을 싣기. 확인하지 못한 단계는 `[확인 필요: 무엇을]` 으로 남긴다.
- 배경 설명을 빠른 시작보다 앞에 길게 두기.
