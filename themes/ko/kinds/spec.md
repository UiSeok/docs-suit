# 기획서

만들 사람과 결정할 사람이 같은 그림을 보게 하는 문서다.

쓰기 전에 받을 것
- 풀려는 문제의 근거. 사용자 불편 사례와 지표, 요청 원문이다.
- 목표 지표의 지금 값.
- 정해진 일정과 이번에 하지 않을 것.

골격
- 한 줄 요약으로 시작한다. 누구의 어떤 문제를 무엇으로 푸는지다.
- 절의 순서는 배경과 문제, 목표 지표, 사용자와 시나리오, 요구 사항, 범위 밖, 일정, 열린 질문이다.
- 목표 지표는 지금 값과 목표 값을 같이 쓴다.
- 요구 사항은 번호를 붙인 표로 쓴다. 열은 "번호, 요구, 우선순위, 확인 방법" 이다.
- 범위 밖을 꼭 쓴다.
