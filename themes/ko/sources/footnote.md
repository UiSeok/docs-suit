# 각주

- 근거가 필요한 문장 끝에 `[1]` 을 붙이고, 문서 끝 "각주" 절에 `[1] 근거 설명.` 꼴로 적는다.
- 출처를 본문 문장으로 쓰지 않는다. "2026년 통계청 자료에 따르면" 대신 각주로 뺀다.
- 수치에는 단위와 비교 기준을 붙인다. 예: "340ms → 88ms", "전년 대비".
- 직접 열어 보지 않은 출처는 달지 않는다. AI 가 알려 준 논문과 기사는 직접 찾아 확인한 뒤에만 단다.
