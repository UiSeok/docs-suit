# 내 문체 문서 쓰기

사용자가 예전에 쓴 글에서 축으로 잡히지 않는 버릇을 뽑아 짧은 규칙 문서로 쓴다. 어법과 문체, 분량, 강조는 `learn` 이 잰 값을 `set` 으로 남기므로 여기서 다시 적지 않는다. 다 쓴 초안은 사용자에게 보이고, 사용자가 고치거나 승인한 판만 `voice set` 으로 남긴다.

무엇을 적는가
- 문장을 잇고 끊는 습관. 즐겨 쓰는 연결어미와 문장 길이의 결이다.
- 글을 여는 방식과 맺는 방식. 결론부터 여는지, 상황부터 여는지다.
- 즐겨 쓰는 구조. 표와 목록을 언제 쓰는지, 예를 어디에 두는지다.
- 일부러 피하는 표현과 자주 고르는 낱말의 결. 낱말 목록 대신 "외래어보다 우리말 동사를 고른다" 처럼 범주로 쓴다.

지킬 것
- 서로 다른 샘플 세 편 이상에서 보인 버릇만 적는다. 한 편에만 있는 것은 그 글의 주제나 자리에서 온 버릇이다.
- 샘플의 소재와 사실, 수치, 사람과 회사와 제품의 이름을 적지 않는다. 예를 들어야 하면 정류장 대기 시간 조사처럼 중립 소재로 바꿔 쓴다.
- 맞춤법 실수와 비문, 한 번만 나온 표현은 버릇으로 보지 않는다.
- `learn` 이 AI 가 쓴 글일 수 있다고 표시한 샘플은 사용자가 직접 썼다고 하지 않는 한 보지 않는다.
- 공통 바닥과 부딪치는 버릇은 적지 않는다. 대시로 잇기, 과장된 수식어 같은 것이다.
- 버릇마다 "~한다" 꼴의 평어체 한 줄로 쓰고, 열 줄을 넘기지 않는다. 제목은 달지 않는다.

예문
- 기본으로 예문을 두지 않는다. 사용자가 원할 때만 사용자가 고른 발췌를 두 개까지 둔다.
- 발췌는 하나에 300자 안쪽이고 인용 블록(`>`)으로 둔다. 사람과 회사 이름, 연락처, 수치는 가리거나 지운다.

남기기
- 초안 전체를 사용자에게 보이고 빼거나 고칠 줄을 묻는다.
- 승인받은 판을 heredoc 으로 넘긴다. 엔진이 1500자를 넘거나 비밀값이 든 문서는 받지 않는다.
- 샘플 원문은 어디에도 저장하지 않는다.
