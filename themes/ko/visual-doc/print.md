# A4 인쇄

보고서를 A4 종이나 PDF 로 낼 때 쓰는 문서 스타일이다. CSS 는 `print/theme.css` 이고 이 저장소에서 새로 썼다.

- 쪽 크기는 A4 이고 쪽 아래 가운데에 쪽 번호를 찍는다.
- 글꼴은 컴퓨터에 깔린 한글 글꼴을 쓴다. 바깥에서 글꼴을 받지 않아 인터넷이 없어도 같은 모양으로 찍힌다.
- 표와 그림, 인용은 쪽 사이에서 끊지 않는다. 표가 쪽을 넘으면 다음 쪽에 표 머리를 다시 찍는다.
- 인쇄하면 링크 뒤에 주소를 괄호로 붙여 종이에서도 출처를 찾게 한다.
- HTML 로 내보낼 때는 `<link rel="stylesheet" href="theme.css">` 한 줄로 붙이고, 브라우저의 인쇄에서 PDF 로 저장한다.
