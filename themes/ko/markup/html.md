# HTML

브라우저로 열거나 파일로 나눠 줄 문서다. 문서 디자인 축의 규칙이 함께 실린다.

- 파일 하나짜리 HTML 로 낸다. 제목은 `<h1>` 하나로 시작하고, 절은 `<h2>`, `<h3>` 로 나눈다.
- 표는 `<table>` 로, 그림은 `<figure>` 와 `<figcaption>` 으로 쓴다.
- 외부 글꼴과 스크립트를 불러오지 않는다.

## 보기

```html
<h1>8시대 버스 증차 제안</h1>
<table><tr><th>시간대</th><th>평균 대기</th></tr><tr><td>8시</td><td>12분</td></tr></table>
```
