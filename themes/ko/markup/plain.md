# 서식 없음

메일 본문, 메신저, 지원서 입력 칸처럼 서식이 먹지 않는 곳에 붙여 넣는 글이다.

- 마크다운 기호를 쓰지 않는다. `#` 제목, `**` 굵은 글씨, `|` 표, 코드 블록을 쓰지 않는다.
- 이 규칙이 그림과 강조 규칙보다 앞선다. 표로 보일 것은 한 줄에 한 항목씩 풀어 쓴다.
- 절을 나눌 때는 빈 줄과 짧은 소제목 한 줄을 쓴다. 소제목 앞뒤에 기호를 붙이지 않는다.
- 목록은 줄 앞에 `-` 나 `1.` 만 붙인다. 들여쓰기로 단계를 만들지 않는다.
- 링크는 주소를 그대로 적는다.
