# 시작 프롬프트

테마 지침을 넣은 대화에서 일을 맡길 때 쓰는 첫 메시지다. 빈칸을 채워 붙여 넣는다.

상황 칸은 요약하지 말고 길게 쓴다. 요약하는 순간 무엇이 빠졌는지는 요약한 사람도 모르고, 일부만 받은 AI 는 빈칸을 그럴듯한 통념으로 채운다. 다만 꼭 지킬 조건은 줄글 속에 묻지 말고 마지막에 목록으로 따로 뽑는다. 줄글에 묻힌 조건은 AI 가 건너뛰기 쉽다.

```
[상황]
나는 ____ 이고, 지금 ____ 을 하려고 한다. 이걸 하는 이유는 ____ 이고,
결과물은 ____ 가 읽는다. 지금까지 해 본 것과 막힌 지점은 ____ 이다.
(생각나는 대로 길게 써도 된다)

[원문]
(과제 안내문, 채용 공고, 자료, 메모를 요약하지 말고 통째로 붙인다)

[꼭 지킬 조건]
- 마감, 분량, 형식처럼 어기면 안 되는 것만 적는다

[요청]
시작 전에, 틀리면 결과가 쓸모없어지는 것만 두세 개 물어봐.
```
