# 검토 프롬프트

다 쓴 글을 검토받을 때는 새 대화를 연다. 같은 대화에서 검토를 맡기면 AI 가 자기가 쓴 글의 전제를 그대로 믿는다. 앞선 대화를 보여 주지 않은 독립 검토가 같은 실수를 더 잘 잡는다.

```
아래 글을 처음 보는 깐깐한 채점자로서 검토해 줘. 칭찬은 빼고 아래 순서로만 짚어.

1. 원문(과제 안내문, 채용 공고)이 요구했는데 빠진 것
2. 근거 없이 단정한 문장과 출처를 확인할 수 없는 수치
3. 확인한 사실과 추정이 섞인 문장
4. 읽는 사람이 한 번 읽고 이해하지 못할 문장

지적마다 원문 문장을 그대로 인용하고, 고칠 방향을 한 줄로 붙여.

[원문]
(과제 안내문이나 채용 공고 전체)

[검토할 글]
(다 쓴 글 전체)
```
